Allowed import from another lane: `landmarks/day1-block.js` and `block.js` import `createParkedCar` from `src/vehicles/models.js`.

Test API entries: `test.chunks()` (the streamer's numbers), `test.ensure(x, z, radius)`, `test.city() → { triangles, towers, tall, landmarks, top, beacon, on, litTo, stats }` (the skyline, how far the lights are on, how high the lit floors reach in metres, each generator's counters).

Events I emit: `district:entered { id, was }` (map), `chunk:loaded` and `chunk:unloaded { cx, cz, lod }` (chunks). `geyser:start { x, z, seconds }`, `geyser:end { x, z }`, `coconut:landed { x, z, speed }` and `prop:broken { kind: 'palm', x, z, speed }` (breakables). Every other `prop:broken` is still emitted by vehicles, for the player's car only: traffic and police cars do not break props, and umbrellas do not fly off in wind yet.

Events I listen to: `game:reset` (props stand back up), `quality:changed` (the city is built again at the new detail).

`?day=1`: `block.js` is day 1's whole block, built as it was, with nothing streaming. It is there so day 1's numbers can still be checked.

Stand-ins I left: none. Not yet matching the bible: the nav graph is built once for the whole map instead of per chunk (it is pure data and small); walking edges do not check lights. Since D6-S3 `map.heightAt` and the collision hash filter by level, but **only the player carries a level so far**: vehicles, traffic, deputies and people on foot call `heightAt` without one and get the guess above, so a traffic car on the deck drops to the ground for a moment where Route 44 or Calle Orquídea passes under it, and nothing but the player's car is stopped by the deck's barriers. Each lane should keep `level` on its bodies and pass it.

Hero lots since D6-S3: `hospital`, `sheriff-hq`, `galleria`, `starlite` (Northgate), `clubhouse`, `model-home` (Mallard Greens). Generators: `northgate` (through `gen/streets.js`), `mallardgreens` (its own), `decks` (the overlay). `map.bounds` now reaches x = -3193 and z = -2694.
