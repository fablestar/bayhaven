# Bible · Index

The bible is the full-size vision of Bayhaven, written out as 85 files with a tier on every item. Sessions read only the files their prompt names; start with the canon, `00-canon.md`, which fixes every name, place and number the other files build on.

Each file has a `Tier:` line near the top that says which tiers it covers: A is in the day 9 build at the Mid level, B is the bonus pool before day 9, C is the first month after release, and D is the full vision. Items the line does not cover carry their own tag in the file. Word counts are whitespace-split words of the whole file.
